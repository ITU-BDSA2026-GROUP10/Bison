# Bison

# This project is an app for Ornithology posts

For dafny:

'dotnet new tool-manifest'

'dotnet tool install dafny'

## How to run
in the terminal
> dotnet run

after opening the localhost address write in your http address:
>/obs

>/ob?id=3

>/obs?page=1

>/obs/<firstname%20lastname>?page=2
